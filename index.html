08 / GOOD TO KNOW

Questions,
answered.

Clear answers for your first connection.

Do both people need the app?+

Yes. Both peers need a compatible version running, and the other peer must be listening on the target port.

Does direct mode work over the internet?+

Sometimes. Routers, firewalls, and carrier-grade NAT can prevent inbound connections. A public IP alone does not guarantee reachability; relay support may help where available.

What does a relay handle?+

A relay is part of the connection path when used. Review the current release and source for its exact role, the protections in place, and the connection metadata it can observe.

What if my peer is offline?+

A peer needs to be running and listening to establish a live session. An attempt to connect does not mean the handshake completed.

Where do I find release files and source code?+

Download the latest release or browse the source code on GitHub.
